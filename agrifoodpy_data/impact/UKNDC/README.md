# UK Nationally determined contributions

Nationally determined contributions (NDCs) are national climate action plans under the Paris Agreement detailing how countries intend to reduce greenhouse gas emissions and adapt to climate impacts. Key features include 5-year update cycles, self-defined targets, and progression in ambition.

These include projected and current emissions inventories which can be used to determine
commodity specific 

We combine the reported land use and agricultural emissions in the latest UK NDC report with FAOSTAT reported production numbers to derive agricultural production and land use co2-equivalent emissions factors for items in the FAOSTAT item base.

### Available datasets

- ** UKNDC_FAOSTAT ** Agricultural and land use emission factors for food items in the FAOSTAT item base.
