# Poore and Nemecek 2018

### Avaiable datasets

- **PN18** Weight-averaged impact for commodity LCA impacts, including Water use, co2-equivalent greenhouse gases, land use, water use, eutrophying and acidifying emissions.
- **PN18_regional** Regional values for commodity LCA impacts
- **PN18_FAOSTAT** Global values for LCA impacts, rebased into the FAOSTAT item base
