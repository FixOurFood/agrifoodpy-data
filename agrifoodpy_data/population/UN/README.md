# United Nations World Population Prospects

World population prospects present projection and past estimates of population under different migration and mortality scenarios.
Data can be downloaded from the [World Population Prospects data portal](https://population.un.org/wpp/)

### Available datasets

-**UN** Population for each region, year and projection scenario
